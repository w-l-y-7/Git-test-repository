# 每日记账 App 项目说明

## 项目概述

做一个在 Windows 上运行的本地记账软件，名字叫每日记账。打开就能用，不需要联网，也不用装服务器。

软件的作用：每天花了多少钱、花在哪，随手记下来。想回头看看这个月吃饭花了多少、打车花了多少，都能查。

## 核心需求

- 运行环境：Windows 本地桌面程序
- 记录每日花销，单位人民币（元）
- 花销分类分两级：一级大类 + 二级小类
- 支持按日、按月的花销汇总查看

## 协作规则（整个项目期间必须遵守）

**用户是编程小白，对技术不了解。** 这是最重要的约定，比任何功能都重要。

- 所有技术决策、技术方案、代码逻辑，都要用大白话解释。遇到专业词，先解释再用。
- 技术问题由 AI 负责解决和解释。用户只表达想要什么（功能、体验），AI 负责怎么实现，并把方案讲清楚。
- 每次做技术选择，都列出多个方案和各自优缺点，解释清楚后由用户拍板。
- 开发进展及时同步，用平实的语言，不堆术语。

## 技术选型

- 方案：Python + Tkinter（Python 自带界面工具，无需额外安装）
- 数据存储：SQLite（Python 自带，存在本地文件）
- 选型理由：用户第一次做项目，选最稳妥、出错概率最低的方案

## 花销分类设计

一级大类 9 个，每个下面配二级小类。记账时先选大类，再选小类。

| 一级大类 | 二级小类 |
| --- | --- |
| 餐饮 | 早餐、午餐、晚餐、外卖、零食饮料、聚餐 |
| 交通 | 公交地铁、打车、加油、停车、火车机票、共享单车 |
| 购物 | 日用品、服饰、电子产品、化妆护肤、其他购物 |
| 居住 | 房租、水费、电费、燃气费、物业费、网费话费 |
| 娱乐 | 电影、游戏、旅游、运动健身、其他娱乐 |
| 医疗 | 药品、门诊、体检、其他医疗 |
| 教育 | 书籍、课程培训、文具、其他教育 |
| 人情 | 礼物、红包、请客、其他社交 |
| 其他 | 不归上面任何类的花销 |
