# 每日记账

一个运行在 Windows 上的本地记账小工具。打开就能用，不用联网，账目都存在自己电脑上。

## 它能做什么

- **记账**：随手记下每天花了多少钱、花在哪。花销分两级，9 个一级大类（餐饮、交通、购物等），下面还有小类（早餐、打车、房租……）
- **明细**：按月翻看每一笔记录，记错了也能删
- **汇总**：看任意一个月的支出、收入和结余（收入减支出）
- **收入**：生活费、红包、奖金、理财等收入也能记下来
- **每周**：按周看每天花了多少，配柱状图，一目了然

## 怎么打开

1. 电脑上装好 Python（3.x 都行）
2. 双击 `每日记账App\启动记账.bat`
3. 或者进入 `每日记账App` 文件夹，在命令行里运行 `python main.py`

## 数据存在哪

所有账目都存到 `每日记账App\records.db` 这个文件里，不会上传到任何地方。删除这个文件就等于清空账本，平时不用管它。

## 技术说明

- 界面：Python 自带的 Tkinter
- 数据：SQLite 本地文件
- 全本地运行，无网络请求
